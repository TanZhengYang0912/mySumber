# AI Anomaly Review Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Admin customer-service review page with an AI Anomaly Review that reads the same alert records as Oversight and displays State → Shopping Mall → Equipment context.

**Architecture:** Keep `Alert` as the single source of truth for anomaly status and evidence. Add optional facility/equipment metadata to `Alert`, persist that metadata in Supabase, and expose a pure filtering service under `modules/admin`. Rebuild the Admin Review screen and add a review-only detail screen; leave customer review submission and Oversight status grouping intact.

**Tech Stack:** Flutter/Dart, Provider, Supabase PostgreSQL/Data API, existing `Alert`/`AppState`/`DatasetState` models, `flutter_test`, `flutter analyze`.

## Global Constraints

- Review must use the same alert records and statuses as Oversight.
- The Review default queue is `Pending` plus `Ongoing` (`Investigating` and `Not Fixed`).
- Review must show State → Shopping Mall → Equipment whenever the alert has that relationship.
- Do not add Worker field inspection, photo upload, repair-result, or customer-rating behavior.
- Do not remove the customer-side review submission flow unless a later requirement explicitly asks for it.
- Do not modify CSV assets at runtime.
- Use the existing public Supabase key only; never add a service-role or secret key.
- Keep Inventory, Oversight, and completed modules functionally intact except for the minimum shared-model/navigation changes required by this feature.
- For Supabase schema work, generate the migration with `supabase migration new`, then verify the schema and run advisors before claiming completion.

```dart
class AnomalyReviewQuery {
  final Set<String> statuses;
  final Utility? utility;
  final String? state;
  final String? facilityName;
  final String? equipmentName;

  const AnomalyReviewQuery({
    this.statuses = const {
      AlertStatus.pending,
      AlertStatus.investigating,
      AlertStatus.notFixed,
    },
    this.utility,
    this.state,
    this.facilityName,
    this.equipmentName,
  });
}

class AnomalyReviewFilter {
  static List<Alert> apply(
    Iterable<Alert> alerts,
    AnomalyReviewQuery query,
  );

  static List<String> states(Iterable<Alert> alerts);
  static List<String> facilities(Iterable<Alert> alerts, {String? state});
  static List<String> equipment(Iterable<Alert> alerts, {
    String? state,
    String? facilityName,
  });
}
```
